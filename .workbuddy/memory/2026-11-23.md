## P2-S4b-2（taint.analyze 函数体）完成

- `libs/taint/analyze.mbt` 实现函数内顺序近似：`sink_statement()` 从 primary（最小捕获索引=callee）向上找 call/assignment 语句，用其 end_byte 作 source 上界（**key**：primary.byte_offset 指向 callee，source 嵌套在 sink 参数里 byte 更大，不能用 primary byte 当上界，否则 inline source 全被漏掉）。
- `enclosing_function()` 递归找最近函数 scope；`collect_events()` 前序遍历收集 source（node_kind + text_contains）/ sanitizer（call 类 + callee_contains），各记 start/end/tokens。
- `bound_variable()` 向上 4 层找 declarator/assignment 的 name/left 字段（JS `const x = req.query.q`），找不到退化为文本首个标识符（`req`）。变量名相等用 `identifiers()` 提 ASCII token + `intersects()`。
- 判定：`source.start < sink_end` 且名字与 sink 参数 token 相交 → 到达；sanitizer 包裹 source（`escapeHtml(req.query.x)`）或在 source 后 sink 前且名字相交 → Sanitized；到达无净化 → Confirmed；无到达 → NoSource；非 sink/无树 → NotApplicable（安全默认）。
- **仍未接入 orchestrator**（扫描链路无消费者），输出/golden 完全不变。93/93 单测（+6 条污点对照）、cram 15/15、golden 100%/0%、verify 9 步全绿。
- `taint/moon.pkg` 补 `moonbit-community/treesitter` import。

### 实测坑（S4b-2）
- **MoonBit 多行 if 条件的 `{` 必须在最后一行行尾**：把 `if a &&\n (b || c)\n{` 写成三段会报 `[3002] Unexpected line break, missing {`；改成条件全挤一行 + 行尾 `{`。
