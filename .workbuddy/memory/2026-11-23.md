### 实测坑

## P2-S3（增量缓存）完成

- 新包 `libs/cache`：`entry_key = sha256(path|content_hash|rules_digest|analyzer_version)`，存"文件级 findings（已过抑制、未跨文件去重）+ warnings + bytes + raw_hits"，不存 RawHit → cache 不依赖 parser/query-engine。
- `scoring` 拆 `finding_from_hit` / `finalize_findings`；`orchestrator` 加 CacheCtx、命中统计，规则摘要取自 rules.json 原始字节（改规则即失效，无需 bump manifest 版本）。
- CLI：`--incremental`、`--cache-dir`（默认 `.lunashield-cache`，已 gitignore）；console 末尾多一行 `cache: N hit, M miss`。
- 实测：0/2 → 2/0 → 改文件 1/1；改规则 severity → 0/2 且 findings 变 medium；增量与全量 `findings.json` `cmp` 相同。单测 79/79、cram 15/15、verify 全绿。推送 5803be0。

### 实测坑（重要，纠正 P0 结论）
- **cram 临时目录是按文档共享，不是按块隔离**：同一 .md 内块共用 cwd。症状：新用例 `src/` 残留前一块的 `b.js`，`1 hit` 变 `2 hit`。修法：块用独立子目录 + 先 `rm -rf`。P1 文档 §2.3 #9 与 §M4 补充已改正。
