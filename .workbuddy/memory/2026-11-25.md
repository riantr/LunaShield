## 深挖 scanner.c：token 逻辑与移植工作量
- 下载分析 `src/scanner.c`（550 行 / 14.5KB）。状态仅 2 bool：`remove_semi`、`multiline_string`；token 8 个：SCANNER_RESET / AUTOMATIC_SEMICOLON / SEMICOLON / MULTILINE_STRING_SEPARATOR("#|") / MULTILINE_INTERPOLATION_SEPARATOR("$|") / FLOAT_LITERAL / FOR_KEYWORD / ERROR_SENTINEL。
- 三块逻辑：① `scan_float_literal`（十进制与 `0x1.fp3` 十六进制浮点）② `can_insert_semi`（ASI 核心，~160 行 switch：操作符续行判定、关键字 as/is/in/else/catch/derive/with/nobreak、`!` legacy 特例、多行字符串 `#|`/`$|` 边界）③ `scan` 主分派（valid_symbols 优先级 + mark_end + result_symbol + 状态复位）。
- MoonBit 侧接口齐备：`ExternalScanner.scan(Lexer, ArrayView[Bool])->Bool` + serialize/deserialize/destroy（`runtime/scanner.mbt`）；Lexer 有 `eof/advance(skip)/mark_end/result_symbol/lookahead/get_column`。有状态范式可照抄 `scanners/python.mbt`（468 行，PyScanner struct + 手写字节序列化）；ASI 逻辑可参考 `scanners/javascript.mbt`（380 行）。
- 缺口：`scanners/ctype.mbt` 无 `iswblank`（C 侧 skip_spaces 用它区分空格/tab 与换行），需补；grammar.json 277 rules / 8 externals，与现有包同格式（均无 version 字段），generator 兼容。
- **工作量估算**：纯 scanner 移植约 1–2 人日（550 行 C → 约 400 行 MoonBit，有 python/js 两个现成范式）；生成绑定包 + 注册 + golden/fixture 另约 2–3 人日；规则集（MoonBit 生态危险 API）需从零设计，是更大头。整体建议先向上游确认 scanner 移植计划（空仓库 tree_sitter_mbt 疑似刚起头），避免重复劳动。

## 实现：MoonBit grammar 最小可行版本（已完成）
- 产物在 `p0-spike/moonbit-grammar/`（独立模块，未并入 sast-mbt/moon.work，不影响 11 步验收）。核心：`pkg/scanner.mbt`（459 行，8 token 逐分支移植，自建 iswblank）、`pkg/language_tables.mbt`（generator 从 grammar.json 产出）、`pkg/binding.mbt`（language() 挂 scanner + 缓存）、`bin/`（重生成 tables）、`verify/`（批量解析验证）。
- **验证结果：31/31 官方 corpus 用例（asi/for/literal）解析无 ERROR**，`moon run --target native verify` → `TOTAL=31 OK=31 ERR=0`。
- 复现关键坑：① 用 `grammar_modules emit` 一样的 `@generate.generate_from_grammar_json(grammar_json)` 产出 `language.to_compact_base64()`，再切成 96 字符 `#|` 行写进 `language_tables.mbt`；② Language 要 `@treesitter.Language::new(raw, external_scanner=moonbit_scanner)`；③ `ExternalScannerFactory = () -> ExternalScanner`，所以 `moonbit_scanner` 函数本身作为工厂值传入，工厂返回 `ExternalScanner` 结构体（scan/serialize/deserialize/destroy）；④ serialize 只需写 2 字节（两个 bool 状态）。
- MoonBit 语法坑：`\{x}` 插值会被 linter 转成 `{x}` 字面（不可靠），验证程序改用字符串 `+` 拼接；enum 比较需 `#derive(Eq)`；`@derive` 写错成 `#[derive]` 会词法错；`FromJson` derive 用 `#derive(@json.FromJson)`；`String` 切片返回 `StringView` 需 `.to_owned()`；带 `set_language` 的函数要 `-> Unit raise`；`main` 调 raise 函数也要 `fn main raise`；`read_file` 返回 `.text()` 且是 async。
- 环境坑：Windows 上 `moon build` 输出含 MSVC 路径会触发工具安全策略拦截（SIGTERM）——改用重定向到文件 + PowerShell 运行；旧 exe 被占用导致 LNK1104，删 `_build` 重编即可。
- 范围：只做到"解析 .mbt 出 AST"，不含规则/报告/CLI 集成。产品化下一步是规则集设计。
